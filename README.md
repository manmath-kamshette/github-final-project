# Simple Interest Calculator

## Description
The Simple Interest Calculator calculates the simple interest earned on a principal amount over a specified period at a given annual interest rate.

## Formula
Simple Interest is calculated using the following formula:

**Simple Interest = (P × R × T) / 100**

Where:
- **P** = Principal amount
- **R** = Annual rate of interest (in percentage)
- **T** = Time period (in years)

## Example
Suppose:
- Principal (P) = 10,000
- Rate of Interest (R) = 5%
- Time (T) = 2 years

Calculation:

Simple Interest = (10,000 × 5 × 2) / 100

**Simple Interest = 1,000**

Total Amount = Principal + Simple Interest

**Total Amount = 11,000**

## Features
- Calculates simple interest based on principal, rate, and time.
- Displays the interest earned.
- Calculates the total amount, including interest.
- Easy to understand and use.

## Purpose
This project demonstrates the basic concept of simple interest calculation and provides a simple example for learning and practicing programming and GitHub.
